# 📦 Supabase Backup Guide
Un guide interactif et moderne pour apprendre à sauvegarder l'intégralité de sa base de données et de ses fichiers Supabase.

## 🎯 À quoi sert ce projet ?

Ce tutoriel web a été créé pour expliquer pas à pas comment sauvegarder une base de données Supabase (qui ne propose pas de sauvegardes automatiques sur son plan gratuit). Il couvre :
- La vérification des droits d'accès (Owner).
- L'installation et la configuration des prérequis (Node.js, Docker, Supabase CLI).
- La récupération de la chaîne de connexion (Connection String).
- Les commandes pour exporter le schéma, les données et les rôles.
- La sauvegarde des fichiers physiques (Storage).
- La configuration de la sécurité (Vault).
